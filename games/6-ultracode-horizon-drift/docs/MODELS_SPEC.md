# MODELS SPEC — everything custom in 3D is modelled in Blender through the MCP (port 9882)

Game: **HORIZON DRIFT**, a No-Man's-Sky-style space exploration game in Godot 4.7.2 (see ARCHITECTURE.md).
These models are the *only* external 3D content. They are generated by Python (bpy / bmesh) scripts that you write and run through
`python tools/bmcp.py file <script.py>` (a lock serialises all agents' calls to the one Blender instance — never use your own socket).

## Hard rules
* Port **9882** only. Project folder `<local-path> 5.5 Effort Test\6. Ultracode Effort`. Do not touch any other folder/port/agent.
* No downloads, no Poly Haven / Sketchfab / Hyper3D / Hunyuan integrations, no imported assets. Model everything with bpy/bmesh code.
* Every call is a **fresh Python namespace** and other agents use the same Blender between your calls: each script must be self-contained
  (create -> preview -> export in one call) and must only touch its own collection / objects / materials (prefix your names).
* Scripts live in `blender/<group>_*.py` (keep them; they are the source of truth and let you regenerate). Use `blender/lib_common.py`
  (read it first: materials, bmesh builders, `export_glb`, `preview`, `montage`, `report`).
* The `.blend` is `ultracode_effort.blend`; the models must exist in it (one collection per model, named like the model id).
  Call `L.save_blend()` at the end of each model script (it is serialised by the lock, so it is safe).
* Never "File > New", never close/restart Blender, never delete other agents' collections/objects/materials.

## Conventions
* Units: 1 Blender unit = 1 metre. Blender **Z up**, model **front = Blender +Y**. Export is glTF `export_yup=True` -> Godot Y-up, front = -Z (Godot forward).
* Origin: props/plants/structures: origin at ground contact (bottom-centre, base sits at z=0). Ship: centre of mass. Character: between the feet.
  Pivot-driven parts (limbs, wheels, gear, wings): the child object's origin is the hinge point so Godot can rotate the node by script.
* One `.glb` per model id into `assets/models/<id>.glb` (use `L.export_glb([root_objects], "<id>")`; children are exported with the parents).
* Mesh quality bar: stylised, readable silhouette, no flat default-primitive look. Use tapered/bent branches, layered canopies, noise-displaced rocks,
  bevel-ish chamfers, panel lines, small greebles on hard-surface, emissive accents where the object should glow. Smooth shading with an
  angle threshold (`L.set_smooth_by_angle(ob, 35)`) or smooth organics; flat shading is fine for crystals/hard-surface edges. Check normals.
* Triangle budget: small props 300–3 000, trees/large flora 1 500–8 000, structures 2 000–15 000, hero ship ≤ 30 000, astronaut ≤ 12 000.
  The game scatters hundreds of the small props with MultiMesh: keep them efficient (no needless subdivisions inside).
* Materials: Principled BSDF only (`L.mat(...)`): base colour, metallic, roughness, emission (+strength), alpha for glass/crystals. NO image textures.
  A model should have **2–6 material slots** (e.g. bark / leaves / glow). Give materials unique prefixed names (e.g. `flora_tree_leaf`).
  Choose saturated, biome-appropriate colours (the game also tints some flora per planet, so keep leaf/glow materials separate from trunk/rock ones).
  Emissive materials must have emission strength 2–8 so they bloom in Godot.
* Foliage that should be double sided (leaf cards, grass blades): build thin 2-sided geometry (duplicate faces with flipped normals) — glTF import keeps back faces only if modelled.
* Every model must be **verified twice**: (1) Blender preview montage (`L.preview` + `L.montage`, then Read the PNG) and (2) the Godot import check:
  `powershell -NoProfile -File tools/godot.ps1 -Mode run -Script res://tools/model_viewer.gd -TimeoutSec 90 -GodotArgs "--resolution 400x300 -- models=<id>.glb"`
  then Read `.previews/godot_<id>.png`. Fix whatever looks wrong (scale, orientation, missing parts, black/white materials, inverted normals) and re-export.
* Each agent writes `assets/models/manifest_<group>.json` (see schema) listing every model it finished. Write it at the end (and update after each batch).

## manifest schema (`assets/models/manifest_<group>.json`)
```json
{ "group": "flora1",
  "models": [
    { "id": "tree_broadleaf_a", "file": "tree_broadleaf_a.glb", "kind": "flora",
      "biomes": ["lush"],              // where the game should use it (ids: lush desert frozen volcanic toxic barren ocean exotic swamp radioactive any)
      "size": [5.2, 9.5, 5.0],         // AABB size in GODOT axes (x, y=up, z), metres
      "base_y": 0.0,                   // AABB min y (should be ~0 for ground props)
      "collider": {"shape": "cylinder", "radius": 0.45, "height": 5.0, "offset_y": 0.0},   // simple trunk-ish collider; shape: none|cylinder|sphere|box (box uses "size":[x,y,z])
      "tris": 2400,
      "tintable": ["leaf"],            // material-name substrings the game may re-colour per planet (optional)
      "nodes": {"gear": ["Gear_Front", "Gear_L", "Gear_R"]},   // named nodes the code relies on (ship/character/creature models; see below)
      "notes": "free text: pivots, axes, retract angle, intended use"
    } ] }
```
`kind` ∈ flora | rock | resource | structure | space | creature | ship | character | tool | prop.

   * `Engine_L`, `Engine_R` (engine nacelle + nozzle meshes), `EngineGlow_L`, `EngineGlow_R` (emissive cone/disc at each nozzle exit, long axis along -Y: Godot will scale it

   * `Gear_Front`, `Gear_L`, `Gear_R` — landing legs + foot pads exported in the **deployed** pose; each object's origin is its hinge point inside the hull; they retract by

   * `RampDoor` (optional: side boarding ramp, hinge origin),

## Process per model (all agents)
1. Write `blender/<group>_<model>.py` (self-contained, deterministic seed) -> run via bmcp -> read stdout (tris, size).
2. `L.preview` + `L.montage`, Read the montage png; iterate until it looks good (silhouette, colours, proportions, no holes/inverted faces).
3. `L.export_glb`, then the Godot `model_viewer` check; Read `.previews/godot_<id>.png`. Confirm: orientation (front = -Z), scale, origin at ground, materials, glow.
4. Append to `assets/models/manifest_<group>.json`, `L.save_blend()`.
Finish with a short report: list of ids exported, anything skipped, any naming deviations.
